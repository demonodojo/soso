# C-001 — `memmap2` 0.2.3 no compila para host soso

**Estado:** hecha (firma del stub). El mapa de verdad sigue sin existir.

## Reproducción

`./x.py check compiler/rustc --host x86_64-unknown-soso` (log
`target/self-improvement/tasks/T40/check-host.txt`, exit 1):

`memmap2` 0.2.3 usa `stub.rs` porque el target no es `unix` ni `windows`.
`lib.rs` llama `MmapInner::map(..., populate)` con 4 argumentos y el stub
declara 3 (`E0061`, seis sitios).

## Arreglo

Copia en `config/rust-soso/vendor/memmap2`. `apply-patches.sh` la instala en
el árbol de rust como `src/soso-memmap2` y añade
`[patch.crates-io] memmap2 = { path = "src/soso-memmap2" }` si hay `Cargo.toml`.
El stub acepta `populate` y sigue devolviendo «platform not supported».
`#![allow(warnings)]` porque ese `check` niega avisos.

## Comprobación

`check-host-3.txt`: `Checking memmap2` pasa. El siguiente error es C-002.

## Límite

No hay `mmap` de fichero usable desde este crate: soso no es `unix` y el stub
no llama a `SYS_MMAP`. Rustc que llegue a mapear un fichero fallará en ejecución.
