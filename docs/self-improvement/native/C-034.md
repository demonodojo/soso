# C-034 — `env::split_paths` entra en pánico

**Estado:** hecha.

## Reproducción

Tras C-033, en el guest (`guest-rustc-emit-27.txt`):

```
$ rustc --emit=obj -o /tmp/t.o /tmp/t.rs
thread 'main' (1) panicked at library/std/src/sys/paths/unsupported.rs:18:5:
unsupported
sosh: [rustc salió con código 134]
```

`split_paths` entra en pánico. `rustc` lo usa para partir `PATH` y
`RUST_TARGET_PATH`.

## Qué se hizo

En soso, `split_paths` parte por `:`.

`build-host-28.txt`: exit 0, 1 min 40 s. `guest-rustc-emit-28.txt`: ese
pánico ya no sale. `rustc --emit=obj` termina con código 134:

```
error: error loading target specification: could not find specification for target "x86_64-unknown-soso"
```

`x86_64-unknown-soso` no está entre los targets incorporados. En el guest
no hay `RUST_TARGET_PATH`, y `Path::is_file` de `std` no está implementado.
Eso es C-035, sin implementar.
