# C-097 — `ctype` de glibc sin inicializar

**Estado:** hecha.

## Reproducción

`isspace` de libgit2 leía una tabla nula (page fault en `0xc6`, `filter_registry_insert`).

## Qué se hizo

El PAL llama a `__ctype_init` de glibc al arrancar (`iniciar_ctype` en `init`). Es un `static` `extern_weak` de tipo `Option<fn>`: LLVM borra la comprobación si es un `fn`.
