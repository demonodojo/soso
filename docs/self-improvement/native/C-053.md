# C-053 — no puede crear el fichero de metadata

**Estado:** hecha.

## Reproducción

Tras C-052, en el guest (`guest-rustc-emit-68.txt`) `rustc --emit=obj`
crea el directorio temporal e imprime:

```
error: failed to create the file /tmp/rmetaC4WJK0/full.rmeta: operation not supported on this platform
```

El hilo principal entra en pánico y sale con código 134. El informe ICE
tampoco se escribe («operation not supported on this platform»).
`guest-boot-68.txt` no muestra page fault.

## Qué se hizo

`File::open` en soso sólo aceptaba lectura. Crear un fichero es
`SYS_OPEN` con `O_WRONLY`, `O_CREAT` y `O_TRUNC`. El contenido sigue
sin escribirse desde `File::write`. `build-host-48.txt` termina bien.

`guest-rustc-emit-69.txt`: el error de crear `full.rmeta` ya no sale.
rustc entra en pánico en `rustc_codegen_ssa/src/back/write.rs:1811`
(«failed to spawn coordinator thread») y sale con 134. Eso es C-054,
sin implementar.
