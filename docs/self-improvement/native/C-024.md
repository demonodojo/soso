# C-024 — `logb` sin definir al enlazar `rustc_llvm`

**Estado:** hecha.

## Reproducción

Tras C-023, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-14.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol logb, referenced by
          .../librustc_llvm-4d90b8d93ccb10a6.rlib @ ConstantFolding.cpp.o
```

`logb` está en `libm` del host. El enlace no pedía `-lm`.

## Qué se hizo

Si el enlace pide `-lstdc++`, `tools/wild-soso` añade detrás `-L` con el
directorio de `cc -print-file-name=libm.so` y `-lm`.

`build-host-15.txt`: exit 1, 0 s. `logb` ya no es el error. `wild` deja
`__TMC_END__` sin definir, referenciado por `crtbegin.o`. Eso es C-025,
sin implementar.
