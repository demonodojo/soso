# C-002 — `getrandom` 0.3.3 no tiene backend para soso

**Estado:** medida, no implementada.

## Reproducción

Tras C-001, el mismo `./x.py check compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/check-host-3.txt`, exit 1):

```
error: target is not supported. You may need to define a custom backend
  --> getrandom-0.3.3/src/backends.rs:176
```

## Qué falta

Un backend del crate `getrandom` 0.3.3 que llame al `SYS_GETRANDOM` que ya
expone `soso-rt`. No se implementa en la sesión de C-001.

## Comprobación

El `check` de `compiler/rustc` para host `x86_64-unknown-soso` pasa de
`getrandom` y el log nombra el siguiente fallo, si lo hay.
