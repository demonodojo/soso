# C-002 — `getrandom` 0.3.3 no tiene backend para soso

**Estado:** hecha (backend de `SYS_GETRANDOM`).

## Reproducción

Tras C-001, el mismo `./x.py check compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/check-host-3.txt`, exit 1):

```
error: target is not supported. You may need to define a custom backend
  --> getrandom-0.3.3/src/backends.rs:176
```

## Arreglo

Copia de `getrandom` 0.3.3 en `config/rust-soso/vendor/getrandom`.
`apply-patches.sh` la instala en `src/soso-getrandom` y añade
`getrandom = { path = "src/soso-getrandom" }` al `[patch.crates-io]` del árbol
de rust. El backend `target_os = "soso"` llama a `SYS_GETRANDOM` (78) con la
misma convención que `soso-rt` (`clobber_abi("C")`). El check niega avisos:
el `asm` va en un bloque `unsafe` y el crate permite `unreachable_pub`, que
también salta en `util.rs` al compilarlo como dependencia.

## Comprobación

`check-host-4.txt` (exit 1, 21 s): `Checking getrandom v0.3.3
(.../src/soso-getrandom)` pasa. El siguiente fallo es C-003.

## Límite

No se ha ejecutado `getrandom` dentro del guest. El kernel llena el buffer
entero o falla; un retorno corto se trata como error.
