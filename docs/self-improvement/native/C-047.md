# C-047 — `std::system_error`: Resource deadlock avoided

**Estado:** hecha.

## Reproducción

Tras C-046, en el guest (`guest-rustc-emit-59.txt`) `rustc --emit=obj`
imprime:

```
terminate called after throwing an instance of 'std::system_error'
  what():  Resource deadlock avoided
```

Sale con código 255. `guest-boot-59.txt`: general protection fault en
el `hlt` de `abort` (`rip=0xb747b09`).

`___pthread_rwlock_rdlock` compara el dueño del lock (`+0x18`) con el
tid de `%fs:0x2d0`. Los dos valían 0, así que devolvía EDEADLK y
LLVM lanzaba `system_error`.

## Qué se hizo

El TCB del hilo principal guarda en `%fs:0x2d0` el pid (o 1 si el pid
sale 0). `build-host-40.txt` termina en 0:01:39.

`guest-rustc-emit-60.txt`: esa excepción ya no sale. rustc imprime
`couldn't read /tmp/t.rs: operation not supported on this platform` y
sale con 134. Eso es C-048, sin implementar.
