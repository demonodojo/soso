# C-064 — no está el enlazador `wild-soso`

**Estado:** hecha.

## Reproducción

Tras C-063, en el guest (`guest-rustc-link-93.txt`) `rustc
/tmp/t.rs -o /tmp/t` ya intenta ejecutar el enlazador. Imprime:

```
error: linker `wild-soso` not found
  |
  = note: no such file or directory (os error 2)
```

El nombre no lleva `/`. El kernel resolvía esa cadena tal cual y no
la buscaba en `PATH`. El `wild-soso` del host es un binario de Linux.

## Qué se hizo

`spawn` busca un nombre sin `/` en `PATH`. Hay un ELF de soso en
`/bin/wild-soso` (`user/coreutils`). `guest-rustc-link-94.txt`:
`ls /bin/wild-soso` lo muestra (29904 bytes) y el proceso imprime
`wild-soso: aun no enlaza`.

rustc sigue saliendo con 134: `could not exec the linker` con
`operation not supported`. El proceso ya ha arrancado; lo que falla
después es `Process::wait`. Eso es C-065, sin implementar. T40 no
se cierra.
