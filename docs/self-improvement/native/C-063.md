# C-063 — no se puede ejecutar `wild-soso`

**Estado:** hecha.

## Reproducción

Tras C-062, en el guest (`guest-rustc-link-92.txt`) `rustc
/tmp/t.rs -o /tmp/t` ya construye el `PATH` del enlazador. Luego
imprime:

```
error: could not exec the linker `wild-soso`
  |
  = note: operation not supported on this platform
```

`Command::spawn` del PAL devolvía `unsupported`. rustc sale con
134. `ls /tmp` muestra los objetos temporales y no muestra
`/tmp/t`.

## Qué se hizo

`Command::spawn` llama a `SYS_SPAWN_IO` con el programa y su argv.
`Process` guarda el pid. Hubo que recompilar rustc
(`build-host-56.txt`).

`guest-rustc-link-93.txt`: ya no dice `operation not supported`.
Imprime `linker wild-soso not found` (`no such file or directory`,
error 2) y sale con 134. `/tmp/t` no está. Eso es C-064, sin
implementar. T40 no se cierra.
