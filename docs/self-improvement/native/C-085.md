# C-085 — Std cruzada soso con rustc CI stage1 (no beta stage0)

**Estado:** hecha (parche + log `build-std-soso-12-c085b.txt`).

## Reproducción

Con `download-rustc`, `./x.py build std --stage 1 --host x86_64-unknown-soso`
compilaba `core` con el **beta stage0** (`1.99.0-beta.3`, 2026-08-28) →
`test_binder_constraints`, intrinsics, etc., aunque el vendor está en
`32d94cc9b` (2026-09-07) y el CI stage1 coincide con ese commit.

C-082 (forzar stage0) empeoraba el cruce; quitar C-082 no bastaba porque el
step sigue etiquetado como stage0 en el artefacto std cruzado.

## Qué se hizo

`apply-patches.sh` → `Std::run`: si target contiene `soso`, `download-rustc` y
`build_compiler.stage <= 1`, usar `builder.compiler(1, host)` para compilar la
librería (nightly CI alineada con el árbol).

## Evidencia

- `build-std-soso-12-c085b.txt`: `Building stage1 library artifacts{std} …`,
  `Compiling core`, `Compiling std`, **exit=0** (~19 s).

## Operación

```sh
env -u RUSTFLAGS_BOOTSTRAP -u RUSTC_ALLOW_FEATURES \
  RUSTFLAGS_BOOTSTRAP='--cfg=bootstrap' \
  ./x.py build std --stage 1 --host x86_64-unknown-soso
```
