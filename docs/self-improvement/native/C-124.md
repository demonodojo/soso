# C-124 — Reserva de TLS por hilo para objetos compartidos

**Estado:** hecha. Ficha de [T80](../T80-proc-macros.md).

## Reproducción

El código de un objeto cargado direcciona su TLS con desplazamientos fijos desde el TP; el bloque TLS de cada hilo sólo cubría el del ejecutable.

## Qué se hizo

`instalar_tls` reserva `TLS_RESERVA` (64 KiB) bajo el TCB sin mover el bloque propio, y `dl::tls_instalar` copia las plantillas de los objetos cargados en cada hilo nuevo y en el actual.

## Evidencia

Mismo log. **Límite:** dos objetos comparten ese hueco; sólo es seguro si sus TLS tienen la misma forma (los de libstd la tienen).
