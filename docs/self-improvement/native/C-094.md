# C-094 — Pila de usuario de 64 KiB

**Estado:** hecha.

## Reproducción

`cargo::commands::add::cli` tiene un marco de varias páginas y moría con `rsp == va` (`guest-boot-cargo-6`).

## Qué se hizo

`handle_mmap_fault` crece la pila principal por fallo hasta 8 MiB (`STACK_MAX` en `addrspace.rs`); los 64 KiB de arriba se siguen mapeando al crear el proceso.

## Evidencia

`guest-cargo-version-8.txt`: `cargo -V` imprime la versión.
