# C-127 — `DirEntry::metadata` y `file_type`

**Estado:** hecha. Ficha de [T80](../T80-proc-macros.md).

## Reproducción

El `build.rs` de `proc-macro2` limpia su directorio de sondeo con
`fs::remove_dir_all` y fallaba con «Failed to clean up …/probe: operation not
supported on this platform»: `remove_dir_all` (el de `sys/fs/common.rs`, C-107)
pregunta `file_type()` de cada entrada, que era `unsupported`.

## Qué se hizo

`DirEntry::metadata` y `file_type` en `sys/fs/soso.rs` se resuelven con `stat`
de la ruta.

## Evidencia

`guest-cargo-build-19.txt`: el build script de `proc-macro2` termina y cargo
sigue con `unicode-ident` y `quote`.
