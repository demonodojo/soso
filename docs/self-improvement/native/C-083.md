# C-083 — No heredar `rustc_private` / rustflags al compilar libstd

**Estado:** hecha (parche bootstrap + limpieza config cargo).

## Reproducción

`./x.py build library --stage 1` o `build cargo` con `--target x86_64-unknown-soso`
falla en `core`/`std` con **`E0725`** (features no permitidas) si el proceso
hereda:

- `RUSTC_ALLOW_FEATURES=rustc_private`, o
- `RUSTFLAGS_BOOTSTRAP=-Zallow-features=rustc_private` (típico en shells donde
  se exportó para builds de tools), o
- `src/tools/cargo/.cargo/config.toml` con
  `rustflags = ["-Zallow-features=rustc_private"]` para soso (Cargo aplica eso
  también al workspace de libstd).

## Qué se hizo

- `apply-patches.sh` → `cargo.rs`: `env_remove("RUSTC_ALLOW_FEATURES")` cuando
  `allow_features` está vacío (`Mode::Std`).
- Mismo script: elimina `src/tools/cargo/.cargo/config.toml` si contenía
  `allow-features=rustc_private`.

## Operación

Antes de bootstrap:

```sh
env -u RUSTC_ALLOW_FEATURES -u RUSTFLAGS -u RUSTDOCFLAGS -u RUSTFLAGS_BOOTSTRAP \
  ./x.py build cargo --host x86_64-unknown-soso …
```

Opcional: `RUSTFLAGS_BOOTSTRAP='--cfg=bootstrap'` si hace falta bootstrap cfg
sin restringir features.

## Evidencia

- `build-std-soso-5.txt`: `E0725` con allow-list roto.
- `build-std-soso-6.txt`: sin `E0725` tras entorno limpio; otro bloqueo (rustc
  beta vs fuente).
