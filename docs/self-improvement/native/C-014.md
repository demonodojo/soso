# C-014 — LLVM para soso no define `LLVM_ON_UNIX`

**Estado:** hecha.

## Reproducción

Tras C-013, `./x.py build compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/build-host-3.txt`, exit 1, 24 s):

```
could not determine CMAKE_SYSTEM_NAME from the target `x86_64-unknown-soso`, build may fail
...
-DCMAKE_SYSTEM_NAME=Generic
...
FileSystem.h:711:19: error: 'class llvm::sys::fs::file_status' has no member named 'getSize'
```

El `llvm-config.h` generado dejaba `/* #undef LLVM_ON_UNIX */`. `getSize`
sólo existe con `LLVM_ON_UNIX` o `_WIN32`.

## Qué se hizo

En `llvm.rs`, un target soso define `CMAKE_SYSTEM_NAME=Linux`. soso es
familia unix; `Generic` apagaba `LLVM_ON_UNIX`.

`build-host-4.txt`: exit 1, 18 min 35 s (`-j 8`). `LLVM_ON_UNIX` queda en
1 y `CachePruning.cpp` compila. LLVM termina de instalarse. `rustc_llvm`
busca `llvm/Config/llvm-config.h` en `ci-llvm/include`, que no existe. Eso
es C-015, sin implementar.
