# C-070 — `libz-sys` no encuentra `off_t` en `libc` para soso

**Estado:** hecha.

## Reproducción

Tras C-069 y `config/rust-soso/patch-getrandom-registry.sh`, `./x.py build
cargo --host x86_64-unknown-soso -j 1 --build-dir …/T40/build`
(`target/self-improvement/tasks/T41/build-cargo-5.txt`, exit 1, 14 s):

```
error[E0425]: cannot find type `off_t` in crate `libc`
error: could not compile `libz-sys` (lib) due to 1 previous error
```

## Qué se hizo

`off_t = i64` en `config/rust-soso/vendor/libc/soso.rs`. Script compartido
`patch-libc-soso.py` (rama `target_os = "soso"` en `lib.rs`) usado desde
`apply-patches.sh` y `patch-getrandom-registry.sh` sobre cada `libc-*` del
registry (incluye clonar `0.2.186` desde otra revisión si falta). Tras parche,
conviene borrar la caché de `libc` en
`stage2-tools/.../x86_64-unknown-soso/release/` si el fallo persistía.

## Evidencia

`build-cargo-7.txt` (exit 1, 5 s): `libc v0.2.186` y `libz-sys v1.1.29`
compilan; también `curl-sys`; el primer error pasa a `gix-sec` (C-071).

## Qué falta

C-071. Ampliar `soso.rs` si otras crates piden más tipos de `libc`.
