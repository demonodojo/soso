# C-065 — `wait` no recoge al enlazador

**Estado:** hecha.

## Reproducción

Tras C-064, en el guest (`guest-rustc-link-94.txt`) `/bin/wild-soso`
existe y el proceso imprime `wild-soso: aun no enlaza`. rustc
imprime de todos modos:

```
error: could not exec the linker `wild-soso`
  |
  = note: operation not supported on this platform
```

`Command::spawn` ya había devuelto un pid. `Process::wait` devolvía
`unsupported`. rustc sale con 134.

## Qué se hizo

`Process::wait` llama a `SYS_WAIT` y `ExitStatus` guarda el código.
Hubo que recompilar rustc (`build-host-57.txt`).

`guest-rustc-link-95.txt`: ya no dice `operation not supported`.
Imprime `linking with wild-soso failed: exit status: 1`. El
enlazador sigue escribiendo `wild-soso: aun no enlaza` y no deja
`/tmp/t`. Eso es C-066, sin implementar. T40 no se cierra.
