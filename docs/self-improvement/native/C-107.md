# C-107 — `rmdir` y `remove_dir_all`

**Estado:** hecha.

## Reproducción

rustc y cargo borran directorios temporales: «failed to remove temporary directory».

## Qué se hizo

`rmdir` usa `SYS_UNLINK` (sosofs rechaza directorios no vacíos); `remove_dir_all` es el de `sys/fs/common.rs`.

## Evidencia

`guest-cargo-build-33.txt`.
