# C-134 — `/dev/urandom` y `/dev/random`

**Estado:** hecha. Ficha de [T42](../T42-c-link-imagen.md).

## Reproducción

`mkfs-soso` genera la clave de host leyendo `/dev/urandom` y moría con «no such file or directory»: soso no tiene `/dev`.

## Qué se hizo

`File::open` de esos dos caminos (sólo lectura) devuelve un descriptor reservado que `read` resuelve con `SYS_GETRANDOM`.
