# C-017 — el enlace de `rustc-main` no encuentra `wild-soso`

**Estado:** hecha.

## Reproducción

Tras C-016, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-7.txt`, exit 1, 1 min 40 s).
Los crates del compilador compilaban. El enlace pedía

`/home/jmdiez/Trabajo/demonodojo/soso/target/release/wild-soso`

y ese fichero no existía. Es el `linker` de `[target.x86_64-unknown-soso]`.

## Qué se hizo

`cargo build --release -p wild-soso`. El binario queda en
`target/release/wild-soso`. `wild` ya estaba en `~/.cargo/bin`.

`build-host-8.txt`: exit 1, 0 s. El enlace ya arranca `wild-soso`. `wild`
rechaza `-Wl,-z,origin` y `-Wl,-rpath,$ORIGIN/../lib`. Eso es C-018, sin
implementar.
