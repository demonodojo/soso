# C-012 — `download-rustc` no cruza el host a soso

**Estado:** hecha.

## Reproducción

Tras C-011, `./x.py build compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/build-host.txt`, exit 1, 0 s):

```
assertion `left == right` failed: Cross-compiling is not yet supported with `download-rustc`
  left: x86_64-unknown-linux-gnu
 right: x86_64-unknown-soso
```

`download-rustc` copia el rustc de CI, que es el host de `config.toml`. El
bootstrap se negaba a usarlo cuando el host pedido era otro.

## Qué se hizo

Ese atajo queda sólo si el host del compilador es el de `config.toml`. Un
host soso sigue el camino de compilar, con el rustc de CI como stage
anterior en Linux. El `check` de host soso no pasa por aquí.

`build-host-2.txt`: exit 1, 3 s. El `assert` ya no está. El bootstrap pide
`ninja` para construir LLVM. Eso es C-013, sin implementar.
