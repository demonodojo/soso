# C-067 — `/tmp/t` muere por page fault

**Estado:** hecha.

## Qué se hizo

`load_lazy` no mapeaba `PT_TLS` cuando ningún `PT_LOAD` cubría esa
dirección. `/tmp/t` pasa de 64 KiB y `wild-soso` deja la plantilla
en ese hueco. El PAL la leía y el kernel mataba el proceso. Ahora
esa plantilla queda registrada como región de lectura.

## Evidencia

`guest-rustc-run-100.txt`: `/tmp/t` imprime `hola-t40` y sosh dice
`salió con código 7`.

## Qué falta

Cerrar T40. No se hace en esta sesión.
