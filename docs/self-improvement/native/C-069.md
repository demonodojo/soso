# C-069 — `gix-config-value` asume Unix en soso

**Estado:** hecha.

## Reproducción

Tras C-068 y `config/rust-soso/patch-getrandom-registry.sh`, `./x.py build
cargo --host x86_64-unknown-soso -j 1 --build-dir …/T40/build`
(`target/self-improvement/tasks/T41/build-cargo-4.txt`, exit 1):

```
error[E0433]: cannot find `unix` in `os`
error[E0425]: cannot find function `getpwnam` in crate `libc`
error: could not compile `gix-config-value` (lib) due to 3 previous errors
```

## Qué se hizo

Copia en `config/rust-soso/vendor/gix-config-value`: `target_os = "soso"` entra
en el mismo grupo que Android/Windows (`home_for_user` devuelve `None` y
`~user/` queda como no soportado). `patch-getrandom-registry.sh` sobrescribe
`gix-config-value-0.18.1` en el registry.

## Evidencia

`build-cargo-5.txt` (exit 1, 14 s): `gix-config-value v0.18.1` compila; el
primer error pasa a `libz-sys` (`off_t` en `libc`, C-070).

## Qué falta

C-070. Más adelante, si hace falta `~user/` en soso, haría falta otra vía (no
`getpwnam` de Unix).
