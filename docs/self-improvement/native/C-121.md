# C-121 — rustc acepta `proc-macro` en soso

**Estado:** hecha. Ficha de [T80](../T80-proc-macros.md).

## Reproducción

`dropping unsupported crate type proc-macro for target x86_64-unknown-soso`: el target no es `dynamic-linking`. Ponerlo en el JSON hacía que bootstrap intentara construir `libstd.so` (`Cannot apply relocation R_X86_64_32 to read-only section`).

## Qué se hizo

`apply-patches.sh` (bloque C-121) hace que `invalid_output_for_target` devuelva falso para `ProcMacro` cuando rustc corre en soso. Con `panic=abort` sólo sale un aviso (`ProcMacroCratePanicAbort`).

## Evidencia

`guest-cargo-build-2.txt`: rustc llega hasta el enlazador con `-shared`.
