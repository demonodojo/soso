# C-110 — `read2` de cargo-util interbloqueaba con rustc

**Estado:** hecha.

## Reproducción

`cargo build` con un crate binario se quedaba para siempre: rustc dormía en la
tubería de stderr llena y el hilo de cargo en la de stdout
(`guest-cargo-build-39.txt`, `ps`: rustc `pipe`, cargo `pipe`).

## Qué se hizo

`patch-cargo-util-soso.py`: el `read2` de soso (sin `poll`/`fcntl`) drena stderr
en un hilo y entrega todo a `data` desde el hilo que llama.

## Evidencia

`guest-cargo-build-40.txt`: el interbloqueo desaparece (el siguiente fallo es el
enlace).
