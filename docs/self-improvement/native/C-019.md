# C-019 — `wild` no encuentra `libstdc++`

**Estado:** hecha.

## Reproducción

Tras C-018, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-9.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Couldn't find library `stdc++` on library search path
```

El comando de enlace lleva `-Bdynamic` `-lstdc++`. LLVM se construyó con
el `cc` del host y arrastra esa biblioteca. `wild` no busca el directorio
de gcc.

## Qué se hizo

`tools/wild-soso` pregunta a `cc -print-file-name=libstdc++.so` y, si el
enlace pide `-lstdc++`, inserta `-L` con ese directorio justo antes.

`build-host-10.txt`: exit 1, 0 s. `libstdc++` ya no es el error. `wild`
ve `_start` definido en el objeto de `rustc-main` y otra vez en el
`libstd` de soso del sysroot de CI. Eso es C-020, sin implementar.
