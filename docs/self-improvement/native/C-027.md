# C-027 — `_Unwind_Resume` sin definir al enlazar `libstdc++.a`

**Estado:** hecha.

## Reproducción

Tras C-026, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-19.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol _Unwind_Resume, referenced by
          /usr/lib/gcc/x86_64-linux-gnu/13/libstdc++.a @ sstream-inst.o
```

`_Unwind_Resume` está en `libgcc_eh.a` (`unwind-dw2.o`, `T _Unwind_Resume`).
El enlace no pasa esa biblioteca.

## Qué se hizo

Si el enlace pide `-lstdc++` y no pasa ya `libgcc_eh`, `tools/wild-soso`
añade detrás la ruta de `cc -print-file-name=libgcc_eh.a`.

`build-host-20.txt`: exit 0, 0 s. El binario queda en
`.../x86_64-unknown-soso/stage2/bin/rustc` (226254172 bytes, ELF estático,
sin sección dinámica). En el host, `rustc --version` muere con violación de
segmento (exit 139): `_start` llama a `soso_entry_from_kernel`. Eso es
C-028, sin implementar.
