# C-135 — Argumentos y variables de entorno de más de 4 KiB por elemento

**Estado:** hecha (2026-10-03). Ficha de [T42](../T42-c-link-imagen.md).

## Reproducción

`cargo build` del kernel fallaba con «file name too long» al lanzar el `rustc` de `smoltcp`: su `--check-cfg` con todas las features pasa de 4 KiB en **un solo** argumento, y `user_str` rechazaba cualquier cadena de más de 4096 bytes (el tope valía para rutas, no para argv).

## Qué se hizo

`user_str_max` en `kernel/src/task/syscall.rs`: argumentos hasta 128 KiB y variables hasta 64 KiB por elemento (los totales ya estaban limitados).

## Evidencia

`guest-cargo-build-48.txt` pasa de `file name too long` a enlazar el build script del kernel.
