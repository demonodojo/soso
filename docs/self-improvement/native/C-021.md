# C-021 — `free` sin definir al enlazar `rustc_llvm`

**Estado:** hecha.

## Reproducción

Tras C-020, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-11.txt`, exit 1, 1 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol free, referenced by
          .../librustc_llvm-4d90b8d93ccb10a6.rlib @ SpeculativeExecution.cpp.o
```

Ese objeto es C++ de LLVM. `free` vive en la libc del host. El enlace pide
`-lstdc++` y no `-lc`.

## Qué se hizo

Si el enlace pide `-lstdc++`, `tools/wild-soso` añade detrás `-L` con el
directorio de `cc -print-file-name=libc.so` y `-lc`.

`build-host-12.txt`: exit 1, 0 s. `free` ya no es el error. `wild` deja
`__dso_handle` sin definir, referenciado por `AMDGPUISelLowering.cpp.o`
dentro de `rustc_llvm`. Eso es C-022, sin implementar.
