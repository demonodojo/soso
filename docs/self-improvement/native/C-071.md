# C-071 — `gix-sec` asume Unix y `geteuid` en soso

**Estado:** hecha.

## Reproducción

Tras C-070, `./x.py build cargo --host x86_64-unknown-soso -j 1 --build-dir
…/T40/build` (`target/self-improvement/tasks/T41/build-cargo-7.txt`, exit 1,
5 s):

```
error[E0433]: cannot find `unix` in `os`
error[E0425]: cannot find function `geteuid` in crate `libc`
error[E0599]: no method named `uid` found for struct `Metadata`
error: could not compile `gix-sec` (lib) due to 3 previous errors
```

## Qué se hizo

Vendor `gix-sec`: `soso` junto a WASI (`is_path_owned_by_current_user` →
`Ok(true)`). Registry vía `patch-getrandom-registry.sh`.

## Evidencia

`build-cargo-8.txt`: `gix-sec v0.14.1` compila; falla `filetime` (C-072).

## Qué falta

C-072. Más adelante, uid real en soso si hace falta comprobar propiedad de
credenciales.
