# C-102 — Ficheros: `rename`, `fsync`, bloqueos, `set_len`

**Estado:** hecha.

## Reproducción

`failed to write Cargo.lock`: `rename`, `fsync`, `lock` y `File::set_len` eran `unsupported`.

## Qué se hizo

`rename` (SYS_RENAME), `fsync`/`datasync` (SYS_FSYNC), bloqueos consultivos siempre concedidos (un solo usuario), y `SYS_FTRUNCATE` (94, nuevo; no sube `ABI_VERSION`) para `File::set_len` en `WriteBuf` y `StreamWrite`.

## Evidencia

`build-cargo-76-c102`, `77-c103`.
