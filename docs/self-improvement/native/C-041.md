# C-041 — el desenrollado de una excepción aborta

**Estado:** hecha.

## Reproducción

Tras C-040, en el guest (`guest-boot-39.txt`) el hilo muere en el `hlt`
de `abort`. `guest-boot-40.txt` guarda la dirección de retorno:
`_Unwind_RaiseException_Phase2.cold`. `.init_array` tiene 695
constructores y el arranque no los ejecuta. `crtbegin` registra
`.eh_frame` desde uno de ellos.

## Qué se hizo

Después de resolver los ifunc, `soso_entry_from_kernel` recorre
`SHT_INIT_ARRAY` y llama a cada constructor.

`build-host-36.txt`: exit 0. `guest-boot-44.txt`: el hilo de
compilación ya no llega a `_Unwind_RaiseException_Phase2`. El hilo
principal (pid 5) muere en `abort` durante un constructor.
`guest-rustc-emit-44.txt`: `rustc` sale con código 255. La cadena es
`std::locale::_S_initialize_once` → `__pthread_once_slow` →
`__libc_fatal`. El texto es «The futex facility returned an unexpected
error code.»: la espera usa la syscall 202 de Linux y en soso el futex
es la 26. Eso es C-042, sin implementar.
