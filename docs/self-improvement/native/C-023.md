# C-023 — `crc32` sin definir al enlazar `rustc_llvm`

**Estado:** hecha.

## Reproducción

Tras C-022, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-13.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol crc32, referenced by
          .../librustc_llvm-4d90b8d93ccb10a6.rlib @ CRC.cpp.o
```

`crc32` está en `libz` del host. El enlace no pedía `-lz`.

## Qué se hizo

Si el enlace pide `-lstdc++`, `tools/wild-soso` añade detrás `-L` con el
directorio de `cc -print-file-name=libz.so` y `-lz`.

`build-host-14.txt`: exit 1, 0 s. `crc32` ya no es el error. `wild` deja
`logb` sin definir, referenciado por `ConstantFolding.cpp.o` dentro de
`rustc_llvm`. Eso es C-024, sin implementar.
