# C-072 — `filetime` usa backend Unix/`libc` en soso

**Estado:** hecha.

## Reproducción (antes del parche)

Tras C-071, `./x.py build cargo --host x86_64-unknown-soso`
(`build-cargo-8.txt`): `filetime` caía en `unix/mod.rs` (`MetadataExt`,
`libc`).

## Qué se hizo

Vendor `filetime-0.2.29` con backend `src/soso.rs` (`modified` / `accessed` de
`std::fs::Metadata`, `FileTimes` para symlink). Registry vía el script de
parches.

## Evidencia

`build-cargo-9.txt` (exit 1, 48 s): `filetime v0.2.29` compila; el primer
error pasa a `curl-sys` / `openssl_sys` (C-073).

## Qué falta

C-073.
