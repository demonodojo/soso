# C-036 — `rustc` no puede crear el hilo de compilación

**Estado:** hecha.

## Reproducción

Tras C-035, en el guest (`guest-rustc-emit-29.txt`):

```
$ rustc --emit=obj -o /tmp/t.o /tmp/t.rs
thread 'main' (1) panicked at compiler/rustc_interface/src/util.rs:199:14:
called `Result::unwrap()` on an `Err` value: Error { kind: Unsupported, message: "operation not supported on this platform" }
sosh: [rustc salió con código 134]
```

`spawn_scoped` falla. En soso, `std::sys::thread` es el módulo
`unsupported`. La pila del proceso son 64 KiB y rustc pide unos 17 MiB.

## Qué se hizo

`run_in_thread_with_globals` en soso no usa `std::thread`. Reserva una pila
anónima con `SYS_MMAP`, arranca el trabajo con `SYS_THREAD_SPAWN` y espera
el join con `SYS_FUTEX`. El hilo comparte el TLS del proceso: `std::thread`
abortaría al ver el hueco del hilo actual ya ocupado.

`build-host-31.txt`: exit 0, 5 s. En el guest el pánico de `spawn_scoped` ya
no sale. El hilo (pid 6) entra en el callback de compilación. A continuación
escribe en el mapeo de solo lectura del ELF y el guest se reinicia. Eso es
C-037, sin implementar.
