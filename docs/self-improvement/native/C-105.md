# C-105 — `available_parallelism`

**Estado:** hecha.

## Reproducción

Cargo se negaba a arrancar sin `-j`: «the number of hardware threads is not known».

## Qué se hizo

`sys/thread/soso.rs` usa `SYS_NCPU`; `apply-patches.sh` lo exporta desde `sys/thread/mod.rs`.

## Evidencia

`build-cargo-78-c104.txt`; `cargo build` sin `-j`.
