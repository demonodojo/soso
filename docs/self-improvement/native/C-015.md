# C-015 — `rustc_llvm` no encuentra `llvm-config.h`

**Estado:** hecha.

## Reproducción

Tras C-014, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-4.txt`, exit 1, 18 min 35 s).
LLVM para soso se instala. El `c++` de `rustc_llvm` incluía

`-I.../build/x86_64-unknown-soso/ci-llvm/include`

y ahí no había `llvm-config.h`. El instalado está en

`.../build/x86_64-unknown-soso/llvm/include`.

El build script toma el `llvm-config` de CI de Linux y, al cruzar, sólo
cambia el triple. El host vive en `ci-llvm`; el LLVM local, en `llvm/`.

## Qué se hizo

`rustc_llvm/build.rs` reescribe `-I` y `-L`: si el directorio con el triple
cambiado no existe, prueba `ci-llvm` ↔ `llvm`.

Instalar el std de soso hacía `remove_dir_all` del libdir del host en el
sysroot de CI. Sin ese `libstd` el build script no recompila. Ahora sólo se
borra cuando el target es el propio host.

`build-host-6.txt`: exit 1, 33 s. Ya no falta `llvm-config.h`. El script
llega a `llvm-config --link-static --libs` y el de CI, que es dinámico, no
tiene los `.a`. Eso es C-016, sin implementar.
