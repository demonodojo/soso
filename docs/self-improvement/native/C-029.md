# C-029 — `Instant::now` entra en pánico al arrancar `rustc`

**Estado:** hecha.

## Reproducción

Tras C-028, en el guest (`guest-rustc-version.txt`):

```
$ rustc --version
thread 'main' (1) panicked at library/std/src/sys/time/unsupported.rs:13:9:
time not implemented on this platform
sosh: [rustc salió con código 134]
```

`Instant::now` en `sys/time/unsupported.rs` hace `panic!`. El kernel ya tiene
`SYS_CLOCK_GETTIME` (72).

## Qué se hizo

`library/std/src/sys/time/soso.rs` lee el reloj con `SYS_CLOCK_GETTIME`
(`CLOCK_MONOTONIC` para `Instant`, `CLOCK_REALTIME` para `SystemTime`).
`sys/time/mod.rs` usa ese módulo en soso.

`build-host-21.txt`: exit 0, 1 min 39 s. En el guest
(`guest-rustc-version-21.txt`) ese pánico ya no sale. `rustc --version`
aborta en `install_ctrlc_handler` (`rustc_driver_impl` línea 1660): el
manejador de Ctrl-C devuelve `Unsupported`. Eso es C-030, sin implementar.
