# C-060 — no se borra el objeto temporal

**Estado:** hecha.

## Reproducción

Tras C-059, en el guest (`guest-rustc-emit-87.txt`) `rustc
--emit=obj -o /tmp/t.o` copia el objeto y luego imprime:

```
error: failed to remove /tmp/t.t.942c5e9f45756909-cgu.0.rcgu.o: operation not supported on this platform
```

`ls /tmp` muestra `t.o` y el temporal, los dos de 3728 bytes. rustc
sale con 134 y el hilo que espera el resultado entra en pánico
(`el hilo de rustc no dejó resultado`).

`std::sys::fs::unlink` del PAL devuelve `unsupported`. El kernel ya
tiene `SYS_UNLINK`.

## Qué se hizo

`std::sys::fs::unlink` llama a `SYS_UNLINK` con el camino y su
longitud. Hubo que recompilar rustc (`build-host-53.txt`).

`guest-rustc-emit-88.txt`: `rustc /tmp/t.rs --emit=obj -o /tmp/t.o`
vuelve al prompt. `ls /tmp` muestra `t.o` de 3728 bytes y ya no está
el temporal. Queda el directorio `rmetaL3SGVd`. T40 no se cierra:
falta cambiar la fuente y comprobar que el objeto cambia.
