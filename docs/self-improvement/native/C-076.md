# C-076 — `libssh2-sys` sin `unix` en soso

**Estado:** hecha.

## Reproducción (antes del parche)

Tras C-075, `build-cargo-31.txt`: `curl v0.4.50` compila; falla
`libssh2-sys v0.3.2` — `libssh2_socket_t` y `platform_init` sólo bajo
`#[cfg(unix)]`.

## Qué se hizo

- `config/rust-soso/patch-libssh2-sys-soso.py`: tipo socket para soso;
  `platform_init` en soso llama `libssh2_init(0)` (sin `openssl_sys`, T42);
  `extern crate openssl_sys` sólo en unix real.
- Hook en `patch-getrandom-registry.sh`.

## Evidencia

`build-cargo-32.txt` (exit 1, ~47 s): `libssh2-sys v0.3.2` compila; primer
error: `libgit2-sys` / `openssl_init` → C-077.

## Qué falta

Siguiente error del build de Cargo tras `libssh2-sys`.
