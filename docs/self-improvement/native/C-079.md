# C-079 — crate `git2` sin backend unix en soso

**Estado:** hecha.

## Reproducción (antes del parche)

Tras C-078, `build-cargo-35.txt`: `cargo-util` compila; falla `git2 v0.21.0`
(`bytes2path`, `IntoCString for OsString`, `openssl_env_init` bajo `cfg(unix)`).

## Qué se hizo

- `config/rust-soso/patch-git2-soso.py`: stub `openssl_env_init` en soso;
  `bytes2path` e `OsString::into_c_string` con `os::soso::ffi`.
- Hook en `patch-getrandom-registry.sh`.

## Evidencia

`build-cargo-36.txt` (exit 1, ~14 s): `git2 v0.21.0` compila; primer error:
`is_executable` → C-080.

## Qué falta

Siguiente error del build de Cargo tras `git2`.
