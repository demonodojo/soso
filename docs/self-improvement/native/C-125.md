# C-125 — `munmap` parcial borraba la región entera

**Estado:** hecha. Ficha de [T80](../T80-proc-macros.md).

## Reproducción

`remove_region` quitaba del libro toda región que solapara `[addr, addr+len)`. La glibc de LLVM reserva 128 MiB, desmapea los extremos para alinear y se queda con el medio: ese medio se quedaba sin registro y la primera escritura moría con «sin región mmap».

## Qué se hizo

`task/mmap.rs`: `remove_region` parte la región y conserva lo de fuera (con el `file_offset` ajustado). `handle_mmap_fault` imprime ahora las regiones vecinas.

## Evidencia

No cambia el síntoma de C-126, que resultó otro fallo.
