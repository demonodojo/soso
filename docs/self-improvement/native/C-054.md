# C-054 — no arranca el hilo coordinador

**Estado:** hecha.

## Reproducción

Tras C-053, en el guest (`guest-rustc-emit-69.txt`) `rustc --emit=obj`
ya no falla al crear `full.rmeta`. Entra en pánico en
`compiler/rustc_codegen_ssa/src/back/write.rs:1811`:

```
failed to spawn coordinator thread: Error { kind: Unsupported, message: "operation not supported on this platform" }
```

El hilo principal entra en pánico («el hilo de rustc no dejó resultado»)
y sale con código 134. `guest-boot-69.txt` no muestra page fault.

## Qué se hizo

`std::sys::thread` en soso era el módulo `unsupported`. `Thread::new`
reserva la pila con `SYS_MMAP` y arranca con `SYS_THREAD_SPAWN`. El
padre espera en `SYS_FUTEX`. `build-host-49.txt` termina bien.

`guest-rustc-emit-70.txt`: el error `Unsupported` ya no sale. El hilo
nuevo aborta con «current thread handle already set during thread
spawn»: hereda el TLS del padre. Eso es C-055, sin implementar.
