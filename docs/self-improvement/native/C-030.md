# C-030 — `rustc` no instala el manejador de Ctrl-C

**Estado:** hecha.

## Reproducción

Tras C-029, en el guest (`guest-rustc-version-21.txt`):

```
$ rustc --version
thread 'main' (1) panicked at compiler/rustc_driver_impl/src/lib.rs:1660:6:
Unable to install ctrlc handler: System(Custom { kind: Other, error: Unsupported })
sosh: [rustc salió con código 134]
```

`install_ctrlc_handler` hace `expect` de `ctrlc::set_handler`. En soso ese
registro devuelve `Unsupported` (C-010).

## Qué se hizo

En soso, `install_ctrlc_handler` ignora ese error y sigue sin manejador.

`build-host-22.txt`: exit 0, 1 min 38 s. `guest-rustc-version-22.txt`:

```
$ rustc --version
rustc 1.100.0-nightly
```

`rustc --emit=obj` sobre `/tmp/t.rs` aborta al buscar el sysroot:
`dll_path is not supported on soso` (`guest-rustc-emit-22.txt`). Eso es
C-031, sin implementar.
