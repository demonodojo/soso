# C-066 — `wild-soso` enlaza

**Estado:** hecha.

## Qué se hizo

`/bin/wild-soso` lee los objetos y los `.rlib` que rustc le pasa,
resuelve símbolos, aplica las reubicaciones x86-64 y escribe un
`ET_EXEC` en `0x400000`. `__ehdr_start` apunta a la cabecera.
`__register_frame` queda como un `ret`: el objeto lo trae indefinido
fuerte y el runtime sólo lo llama si el puntero no es nulo.

## Evidencia

`guest-rustc-link-98.txt`: `rustc /tmp/t.rs -o /tmp/t` vuelve al
prompt. `ls /tmp` muestra `/tmp/t` con 102160 bytes. No imprime
«salió con código».

## Qué falta

El programa se ejecutó. No imprime `hola-t40`: el kernel lo mata
por page fault. Eso es C-067. No se cierra T40.
