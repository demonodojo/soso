# C-025 — `__TMC_END__` sin definir al enlazar `crtbegin.o`

**Estado:** hecha.

## Reproducción

Tras C-024, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-15.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol __TMC_END__, referenced by
          /usr/lib/gcc/x86_64-linux-gnu/13/crtbegin.o
```

`__TMC_END__` está en `crtend.o` de gcc. El enlace pasaba `crtbegin.o` y no
`crtend.o`.

## Qué se hizo

Si el enlace pide `-lstdc++`, `tools/wild-soso` añade al final la ruta de
`cc -print-file-name=crtend.o`.

`build-host-16.txt`: exit 0, 0 s. El enlace de `rustc-main` termina. El
binario queda en `.../x86_64-unknown-soso/stage2/bin/rustc` y depende de
bibliotecas compartidas del host. Eso es C-026, sin implementar.
