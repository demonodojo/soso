# C-048 — rustc no lee el fuente

**Estado:** hecha.

## Reproducción

Tras C-047, en el guest (`guest-rustc-emit-60.txt`) `rustc --emit=obj`
imprime:

```
error: couldn't read `/tmp/t.rs`: operation not supported on this platform
```

El fichero existe. El `fs` de `std` en soso era el módulo `unsupported`,
y `File::open` devolvía ese error.

## Qué se hizo

`library/std/src/sys/fs/soso.rs` abre con `SYS_OPEN` (`O_RDONLY`) y lee
con `SYS_READ`. Escribir sigue sin estar. `build-host-41.txt` termina
en 0:01:50.

`guest-rustc-emit-61.txt`: el «couldn't read» ya no sale. rustc llega
a resolver el crate y falla con `can't find crate for std` (E0463).
Eso es C-049, sin implementar.
