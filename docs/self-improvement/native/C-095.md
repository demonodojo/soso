# C-095 — Claves TLS de pthread

**Estado:** hecha.

## Reproducción

libgit2 llama a `pthread_getspecific`; la de glibc lee `%fs:0x10` (`THREAD_SELF`) y morían con page fault en `0x318`.

## Qué se hizo

`libc_tls.rs` en el PAL: `pthread_key_create/delete/getspecific/setspecific` sobre un `#[thread_local]`. El TCB de soso mide ahora `0xa00` bytes y `%fs:0x10` apunta a sí mismo, como espera la `struct pthread` de glibc (stdio, `pthread_self`).

## Evidencia

`build-cargo-71-c098.txt`; el guest pasa de `0x308` a pedir entropía.
