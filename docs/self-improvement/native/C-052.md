# C-052 — no puede crear el directorio temporal

**Estado:** hecha.

## Reproducción

Tras C-051, en el guest (`guest-rustc-emit-67.txt`) `rustc --version`
imprime `rustc 1.100.0-nightly (32d94cc9b 2026-09-07)`. `rustc --emit=obj`
ya no rechaza `std` por versión e imprime:

```
error: couldn't create a temp dir: operation not supported on this platform at path "/tmp/rmetak7M8FY"
```

El hilo principal entra en pánico y sale con código 134. El informe ICE
tampoco se escribe («operation not supported on this platform»).
`guest-boot-67.txt` no muestra page fault.

## Qué se hizo

`DirBuilder::mkdir` en soso era `unsupported`. Ahora llama a `SYS_MKDIR`.
Escribir un fichero sigue sin estar. `build-host-47.txt` termina bien.

`guest-rustc-emit-68.txt`: el directorio temporal ya existe. rustc falla
al crear `/tmp/rmetaC4WJK0/full.rmeta` («operation not supported on this
platform») y sale con 134. Eso es C-053, sin implementar.
