# C-013 — el build de host soso pide `ninja`

**Estado:** hecha.

## Reproducción

Tras C-012, `./x.py build compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/build-host-2.txt`, exit 1, 3 s):

```
Couldn't find required command: ninja (or ninja-build)

You should install ninja as described at
<https://github.com/ninja-build/ninja/wiki/Pre-built-Ninja-packages>,
or set `ninja = false` in the `[llvm]` section of `bootstrap.toml`.
Alternatively, set `download-ci-llvm = true` in that `[llvm]` section
to download LLVM rather than building it.
```

Al dejar de copiar el rustc de CI, el bootstrap quiere construir LLVM.
CI no publica LLVM para soso, así que el build es local y busca `ninja`.
`download-ci-llvm = false` no convive con `download-rustc = true`.

## Qué se hizo

`scripts/soso-rust-bootstrap.sh` y el `config.toml` vivo añaden:

```
[llvm]
ninja = false
```

El generador pasa a `make`, que ya está instalado. No se pone
`download-ci-llvm = false`.

`build-host-3.txt`: exit 1, 24 s. Ya no pide `ninja`. cmake configura
(`CMAKE_SYSTEM_NAME=Generic`) y `gmake` compila hasta `LLVMSupport`:
`file_status` no tiene `getSize` porque `LLVM_ON_UNIX` queda indefinido.
Eso es C-014, sin implementar.
