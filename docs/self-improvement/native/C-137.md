# C-137 — Herramientas para el ciclo con `SOSO_REUSE_DATA=1`

**Estado:** hecha (2026-10-03). Ficha de [T42](../T42-c-link-imagen.md).

## Reproducción

Con `SOSO_REUSE_DATA=1` la imagen de datos se reutiliza tal cual: un `wild-soso`, `rustc` o `cargo` nuevo **no llega al guest** (varias iteraciones «arreglaban» algo que el guest nunca ejecutó), y el `rm -r` nuevo de los coreutils tampoco llega a una imagen reutilizada (ahí sigue el `rm` viejo).

## Qué se hizo

Ejemplos de `crates/sosofs` que operan sobre la imagen con el QEMU parado: `poner` (escribe un fichero), `sacar` (lo copia al host para `readelf` y `objdump`) y `borrar` (quita ficheros por sufijo). En `xtask`, `SOSO_KERNEL_ELF`.

## Evidencia

Usados en las iteraciones 45–58 de `guest-cargo-build-*.txt`.
