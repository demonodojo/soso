# C-050 — no puede mapear el rlib de `std`

**Estado:** hecha.

## Reproducción

Tras C-049, en el guest (`guest-rustc-emit-64.txt`) `rustc --emit=obj`
encuentra la crate y imprime:

```
error[E0786]: found invalid metadata files for crate `std`
  = note: failed to mmap rmeta metadata: '/lib/rustlib/x86_64-unknown-soso/lib/libstd-c0d12c2bb54f24f0.rmeta'
  = note: failed to mmap file '/lib/rustlib/x86_64-unknown-soso/lib/libstd-c0d12c2bb54f24f0.rlib': operation not supported on this platform
```

El hilo principal entra en pánico y sale con código 134. Sin page fault.

## Qué se hizo

`File::metadata` no tenía `SYS_FSTAT`, así que memmap2 ni llegaba a
mapear. rustc no llama a `Mmap::map`: usa `map_copy_read_only`. En
soso ese mapa es `SYS_MMAP` de sólo lectura sobre el fd.
`build-host-44.txt` y `build-host-45.txt` terminan bien.

`guest-rustc-emit-66.txt`: E0786 ya no sale. rustc lee el metadata y
rechaza la crate por versión (E0514). Eso es C-051, sin implementar.
