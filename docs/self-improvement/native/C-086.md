# C-086 — `url::Url::from_file_path` en soso

**Estado:** hecha (parche registry + log).

## Reproducción

`./x.py build cargo --host x86_64-unknown-soso` tras C-081/C-085:

```
error[E0599]: no associated function or constant named `from_file_path` found for struct `Url`
  --> cargo-util-schemas/.../package_id_spec.rs:88:38
```

La crate `url` 2.5.x expone `from_file_path` / `to_file_path` sólo bajo
`any(unix, windows, redox, wasi, hermit)`; soso no entra en `unix`.

## Qué se hizo

- `patch-url-soso.py`: añade `target_os = "soso"` a esos `cfg` y `OsStrExt` vía
  `std::os::soso::ffi` en los helpers de paths `file://`.
- `patch-getrandom-registry.sh`: aplica el parche a `url-*` en el registry.

## Evidencia

- `build-cargo-49.txt`: sigue el `E0599` con `url` en caché sin recompilar.
- Tras `patch-getrandom-registry.sh` y limpiar `stage2-tools/.../build/url`:
  `build-cargo-50.txt` recompila `url v2.5.8` y **no** vuelve a fallar
  `cargo-util-schemas` / `from_file_path`. Siguiente error: `cargo-credential`
  (`imp`) y `tar` (`path2bytes`).
