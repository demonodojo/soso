# C-075 — crate `curl` sin backend unix en soso

**Estado:** hecha.

## Reproducción (antes del parche)

Tras C-074, `./x.py build cargo --host x86_64-unknown-soso`
(`build-cargo-30.txt`): `socket2 v0.6.4` compila; falla `curl v0.4.50` (~19
errores): `cvt` en `open_socket` sólo bajo `#[cfg(unix)]`, y `path2cstr` /
`setopt_path` igual. En soso no hay `std::os::unix` ni `cfg(unix)`.

## Qué se hizo

- `config/rust-soso/patch-curl-soso.py`: `#[cfg(unix)]` →
  `any(unix, target_os = "soso")` en `multi.rs`; paths con
  `std::os::soso::ffi::OsStrExt`; `open_socket`/`cvt` con rama soso que usa
  `socket.into_raw_fd()` inherente.
- `patch-socket2-soso.py`: `Socket::into_raw_fd` público en soso (C-075) para
  libcurl sin prelude unix.
- Hook en `patch-getrandom-registry.sh` para `curl-0.4.50`.

## Evidencia

`build-cargo-31.txt` (exit 1, ~61 s): tras recompilar `socket2` con
`into_raw_fd` inherente, `curl v0.4.50` compila; primer error:
`libssh2-sys` → C-076.

## Qué falta

Siguiente error del build de Cargo tras `curl`.
