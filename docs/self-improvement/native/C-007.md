# C-007 — `rustc_sanitizers` no encuentra tipos de `libc`

**Estado:** hecha.

## Reproducción

Tras C-006, `./x.py check compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/check-host-10.txt`, exit 1):

```
error[E0432]: unresolved import `libc::size_t`
 --> compiler/rustc_sanitizers/src/ignorelist/ffi.rs:6:5

error[E0425]: cannot find type `c_char` in crate `libc`
  --> compiler/rustc_sanitizers/src/ignorelist/mod.rs:28:38
```

`libc` no publica `size_t` ni `c_char` para `target_os = "soso"`. En x86_64
`size_t` es `usize` y `c_char` es `std::ffi::c_char`.

## Qué se hizo

`apply-patches.sh` deja el import de `libc::size_t` en el resto de targets.
En soso, `ignorelist/ffi.rs` define `size_t` como `usize` y nombra `libc`.
`ignorelist/mod.rs` usa `std::ffi::c_char` en soso y `libc::c_char` en el resto.

`check-host-11.txt`: `Checking rustc_sanitizers` pasa. El check sigue en
exit 1 por `rustc_codegen_llvm`. Eso es C-008, sin implementar.
