# C-035 — `rustc` no encuentra la especificación del target

**Estado:** hecha.

## Reproducción

Tras C-034, en el guest (`guest-rustc-emit-28.txt`):

```
$ rustc --emit=obj -o /tmp/t.o /tmp/t.rs
error: error loading target specification: could not find specification for target "x86_64-unknown-soso"
sosh: [rustc salió con código 134]
```

`load_builtin("x86_64-unknown-soso")` no devolvía especificación.

## Qué se hizo

`x86_64-unknown-soso` queda incorporado. La especificación es el JSON de
`x86_64-unknown-soso.json`, sin buscarlo en disco.

`build-host-29.txt`: exit 0, 1 min 42 s. `guest-rustc-emit-29.txt`: el error
de la especificación ya no sale. `rustc --emit=obj` entra en pánico en
`rustc_interface/src/util.rs:199`: `spawn_scoped` devuelve
`operation not supported on this platform`. El hilo de `std` en soso es el
módulo `unsupported`. Eso es C-036, sin implementar.
