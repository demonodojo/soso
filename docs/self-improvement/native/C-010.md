# C-010 — `ctrlc` no tiene plataforma para soso

**Estado:** hecha.

## Reproducción

Tras C-009, `./x.py check compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/check-host-16.txt`, exit 1):

```
error[E0432]: unresolved import `platform::Signal`
  --> .../ctrlc-3.5.1/src/lib.rs:53:9
   |
53 | pub use platform::Signal;
   |         no `Signal` in `platform`
```

`platform/mod.rs` sólo incluye unix y Windows. Faltaban `Signal`, `Error`,
`init_os_handler` y `block_ctrl_c`. El crate lo arrastra `rustc_driver`.

## Qué se hizo

`apply-patches.sh` copia `ctrlc` 3.5.1 a `src/soso-ctrlc` y lo engancha con
`[patch.crates-io]`. La plataforma de soso publica esos símbolos.
`init_os_handler` devuelve error: soso no instala un manejador de Ctrl-C.
Unix y Windows no cambian.

`check-host-17.txt` negó avisos (`Formatter` sin vida y `unreachable_pub`).
`check-host-18.txt`: exit 1, 78 s. `Checking ctrlc` pasa. El binario
`rustc-main` no encuentra el crate `rustc_driver`. Eso es C-011, sin
implementar.

**Límite.** Ctrl-C no queda registrado.
