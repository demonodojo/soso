# C-003 — `rustc_fs_util` importa `CString` que en soso no se usa

**Estado:** hecha (el import sigue el `cfg` de la función).

## Reproducción

Tras C-002, `./x.py check compiler/rustc --host x86_64-unknown-soso`
(`target/self-improvement/tasks/T40/check-host-4.txt`, exit 1):

```
warning: unused import: `CString`
 --> compiler/rustc_fs_util/src/lib.rs:1:16
error: warnings are denied by `build.warnings` configuration
```

`path_to_c_string` —el único uso de `CString`— está bajo
`cfg(unix)`, WASI p1 o Windows. En `target_os = "soso"` esa función no se
compila y el import queda muerto. El check niega avisos.

## Arreglo

`apply-patches.sh` parte el import: `OsStr` sigue siempre (lo usa
`TempDirBuilder`); `CString` lleva el mismo `cfg` que `path_to_c_string`.
Unix, WASI y Windows no cambian.

## Comprobación

`check-host-5.txt` (exit 1, 20 s): `Checking rustc_fs_util` pasa. El
siguiente fallo es C-004.
