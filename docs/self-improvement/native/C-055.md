# C-055 — el hilo nuevo hereda el TLS del padre

**Estado:** hecha.

## Reproducción

Tras C-054, en el guest (`guest-rustc-emit-70.txt`) `rustc --emit=obj`
arranca el hilo coordinador y aborta:

```
fatal runtime error: current thread handle already set during thread spawn, aborting
```

El padre se queda esperando el join: el aborto no publica la palabra
de `SYS_THREAD_SPAWN`. `guest-boot-70.txt` no muestra page fault.

## Qué se hizo

Antes de `ThreadInit::init`, el hilo instala su propia imagen TLS
(`SYS_MMAP` de la plantilla `PT_TLS` y `SYS_SET_TLS`). El tid sale de
`SYS_GETPID` de ese hilo. `build-host-50.txt` termina bien.

`guest-rustc-emit-72.txt`: el aborto ya no sale. rustc sigue en CPU
más de 20 minutos, sin page fault y sin otro diagnóstico. No hay
ficha nueva hasta que ese emit termine o imprima un fallo distinto.
