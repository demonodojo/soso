# C-091 — OpenSSL estático en el bin `cargo` (libgit2/libssh2/curl)

**Estado:** hecha.

## Reproducción

Tras C-090, `build-cargo-56.txt`: el enlace pasa `-lz`; falla con símbolos
OpenSSL (p. ej. `EVP_MAC_init`) referenciados desde `libssh2_sys` /
`libgit2_sys` / `libcurl_sys`. rustc no añade `-lssl`/`-lcrypto`.

## Qué se hizo

En `tools/wild-soso`, `with_openssl_libs`: si la línea de enlace menciona
alguno de esos crates `-sys` y no hay ya `-lssl`, inserta `-Bstatic`,
`-L` del host (`libssl.so` / `libssl.a`) y `-lssl -lcrypto`.

## Evidencia

- Progresión en logs `build-cargo-56` → `57` (OpenSSL resuelto; siguiente
  bloqueo `__dso_handle`, cubierto por crt en C-090).
- `build-cargo-60.txt`: enlace del bin `cargo` completo, exit 0.
