# C-040 — el hilo de compilación salta a la dirección 0

**Estado:** hecha.

## Reproducción

Tras C-039, en el guest (`guest-boot-38.txt`) el hilo muere con page fault
en `0x0`, `rip=0x0`. Es una llamada a un puntero nulo.

El binario tiene 32 reubicaciones `R_X86_64_IRELATIVE` en `.rela.plt`
(`memchr`, `sincos` y el resto de ifunc de glibc). El hueco queda a 0
porque el arranque no llama al resolvedor. La primera llamada salta a
esa dirección.

## Qué se hizo

Después de preparar el TLS, `soso_entry_from_kernel` recorre las
secciones `SHT_RELA`, llama a cada resolvedor y escribe el puntero en
su hueco.

`build-host-35.txt`: exit 0. `guest-boot-39.txt`: ya no hay page fault
con `rip=0`. El hilo muere en `abort` de glibc (`hlt`). La dirección de
retorno (`guest-boot-40.txt`) es `_Unwind_RaiseException_Phase2.cold`.
Eso es C-041, sin implementar.
