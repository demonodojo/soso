# C-051 — la crate `std` es de otra versión de rustc

**Estado:** hecha.

## Reproducción

Tras C-050, en el guest (`guest-rustc-emit-66.txt`) `rustc --emit=obj`
lee el metadata e imprime:

```
error[E0514]: found crate `std` compiled by an incompatible version of rustc
  = note: crate `std` compiled by rustc 1.100.0-nightly (32d94cc9b 2026-09-07): /lib/rustlib/x86_64-unknown-soso/lib/libstd-c0d12c2bb54f24f0.rmeta
  = help: please recompile that crate using this compiler (rustc 1.100.0-nightly)
```

El compilador del guest se anuncia como `rustc 1.100.0-nightly`, sin
el hash que llevan los `.rlib`. Sale con código 134. `guest-boot-66.txt`
no muestra page fault.

## Qué se hizo

El canal de `config.toml` es `dev`. Con `download-rustc`, el bootstrap
lo sustituye por el del CI (`nightly`), pero `omit-git-hash` se decide
antes y, en canal `dev`, vale true. `CFG_VERSION` queda en
`1.100.0-nightly`, sin `(32d94cc9b 2026-09-07)`.

`scripts/soso-rust-bootstrap.sh` pone `omit-git-hash = false`.
`build-host-46.txt` termina bien. No se recompilaron los `.rlib`.

`guest-rustc-emit-67.txt`: `rustc --version` imprime
`rustc 1.100.0-nightly (32d94cc9b 2026-09-07)`. E0514 ya no sale.
rustc no crea `/tmp/rmetak7M8FY` («operation not supported on this
platform») y sale con 134. Eso es C-052, sin implementar.
