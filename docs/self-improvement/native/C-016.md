# C-016 — `llvm-config` de CI no lista bibliotecas estáticas

**Estado:** hecha.

## Reproducción

Tras C-015, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-6.txt`, exit 1, 33 s).
El build script pedía `--link-static --libs` al `llvm-config` de CI. Ese
LLVM es dinámico y no tiene `.a`, así que el comando sale 1. Los `.a` de
soso están en `.../x86_64-unknown-soso/llvm/lib`.

## Qué se hizo

Si al cruzar existe el `llvm-config` del target y se puede ejecutar, `--libs`
y `--ldflags` usan ese. El de soso es un ELF de Linux (lo compiló el `cc`
del host) y lista las bibliotecas estáticas.

`build-host-7.txt`: exit 1, 1 min 40 s. `rustc_codegen_llvm` y
`rustc_driver` compilan. El enlace de `rustc-main` no encuentra
`wild-soso`. Eso es C-017, sin implementar.
