# C-022 — `__dso_handle` sin definir al enlazar `rustc_llvm`

**Estado:** hecha.

## Reproducción

Tras C-021, `./x.py build compiler/rustc --host x86_64-unknown-soso -j 8`
(`target/self-improvement/tasks/T40/build-host-12.txt`, exit 1, 0 s):

```
error: linking with `.../target/release/wild-soso` failed: exit status: 255
  = note: wild: error: Undefined symbol __dso_handle, referenced by
          .../librustc_llvm-4d90b8d93ccb10a6.rlib @ AMDGPUISelLowering.cpp.o
```

`__dso_handle` está en `crtbegin.o` de gcc. El enlace no pasaba ese objeto.

## Qué se hizo

Si el enlace pide `-lstdc++`, `tools/wild-soso` inserta delante la ruta de
`cc -print-file-name=crtbegin.o`.

`build-host-13.txt`: exit 1, 0 s. `__dso_handle` ya no es el error. `wild`
deja `crc32` sin definir, referenciado por `CRC.cpp.o` dentro de
`rustc_llvm`. Eso es C-023, sin implementar.
