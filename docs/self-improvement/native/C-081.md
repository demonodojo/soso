# C-081 — `cargo-util-terminal` sin `mod imp` en soso

**Estado:** hecha (parche + log).

**Evidencia:** `build-cargo-48.txt` — `Compiling cargo-util-terminal`, warning
en `shell.rs`, sin error de `mod imp`.

## Reproducción (antes del parche)

Tras C-080, `build-cargo-37.txt`: `is_executable` compila; falla
`cargo-util-terminal` con `cannot find module or crate imp` en
`shell.rs` (`stderr_width`, `err_erase_line` bajo lógica unix).

## Qué se hizo

- `config/rust-soso/patch-cargo-util-terminal-soso.py`: `imp` unix excluye
  soso; stub soso (`stderr_width` → `NoTty`, borrado ANSI `\x1B[K`).
- Hook en `apply-patches.sh` junto a C-078 (`cargo-util`).

## Evidencia

Parche aplicado en
`~/.cache/soso-rust-vendor/.../cargo-util-terminal/src/shell.rs` (marcador
`C-081 soso`).

`build-cargo-38.txt` (exit 1): no llegó a recompilar el crate; el bootstrap
petó al enlazar `StdLink` / recompilar `std` para soso (artefactos ausentes
en el sysroot tras intentos de build con `soso-rt` mal apuntado). Repetir
`apply-patches.sh` y `./x.py build cargo --host x86_64-unknown-soso
--build-dir …/T40/build` con el árbol en estado coherente.

Confirmar en log que `cargo-util-terminal` compila y capturar el siguiente
error del workspace de Cargo.
