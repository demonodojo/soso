### Decisiones que conviene recordar

- **Tramo no interrumpible:** como máximo **un forward completo de capa** (desde que
  empieza `exec.forward_layer` hasta que termina). La cancelación entre capas se
  evalúa **antes** de cada capa, no a mitad de matmul/atención.
- Prefill sin slot de cancel usa `NoCancelObserver` + ledger scratch; solo las rutas
  `*_observed` / `prefill_prompt_with` exponen cancel real.
- `forward_layers_range_clock` recibe `&mut Option<&mut dyn GenerationObserver>` para
  poder re-prestar el observador en cada capa sin mover el `Option`.
- Tras cancelar, no se llama `on_token` ni `accept_sample` adicional; el informe lleva
  `StopReason::Cancelled`.
